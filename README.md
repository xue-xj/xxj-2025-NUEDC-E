# 25电赛E题

K230 与 MSPM0G3507 双轴视觉云台系统 V1.0

面向2025年全国大学生电子设计竞赛E题的矩形目标识别与二维云台控制工程。
K230负责图像处理、增量PI和触摸阈值界面，MSPM0G3507负责完整串口帧解析、模式控制及两路STEP脉冲输出。

## 公开版依赖

本仓库包含自编视觉、协议、运动控制和显示调度代码，以及接线、部署与测试文档。
**OLED 绘图驱动及字模尚未确认再分发授权，因此不提供 `mspm0/oled.c`、`oled.h`、`oledfont.h` 和 `bmp.h`。**
MCU 完整构建前需合法补齐兼容的 OLED 接口，并安装 TI SDK、SysConfig 和编译器；详见 [外部依赖](docs/external-dependencies.md)。
K230 端程序不依赖上述 MCU OLED 文件。公开版不含固件、工具安装包和本地私有配置。

## 功能

- 320×240图像灰度二值化、膨胀、矩形几何／中心黑色比例筛选，选择满足条件的最小矩形。
- 连续2帧确认目标，短时丢失保持角点，连续5帧丢失后停止发送跟踪数据。
- 增量PI将图像误差转换为方向和步数，每帧每轴最大50步。
- 800×480本地显示与触摸阈值调节，不需要电脑连接即可调整；应用值仅在当前运行有效，重启回默认。
- MCU支持手动微调、视觉跟踪和闭合四段扫描；扫描期间有效视觉指令优先切入跟踪。
- 12字节双轴协议，X/Y独立校验，校验完成后原子交接整帧，避免半帧动作。
- PWM在CC0下降沿递减预算并停止；OLED用非阻塞I2C事务发送，控制循环不等待整屏刷新。

## 操作

1. MCU默认扫描；PB27模式按键依次切换扫描 → 手动 → 跟踪 → 扫描。
2. K230首次按GPIO53按键启用坐标发送；之后按键发送一次零步控制包并继续跟踪，不是机械回零。
3. 持续触摸约21帧进入阈值编辑，返回放弃，应用使用当前数值。画面中的目标十字为(156,113)。
4. 目标丢失后跟踪模式保持，不自动回扫描；需要再次搜索时通过MCU模式键选择扫描。

## 构建与验证

补齐 OLED 依赖的完整本地工程已执行 TI SysConfig、13 个 C 文件编译及完整链接；另有 9 项 Python 测试和 5 组真实 ARM C 模拟测试。上述结果不表示缺失 OLED 依赖的公开版本身可直接完整构建。
命令、工具版本及验证边界见 [部署](docs/deployment.md) 和 [验证记录](docs/validation.md)。
尚未实板验证摄像头／触摸、I2C时序、STEP边沿数量、机械行程和跟踪效果。不能用主机测试替代整机验收。
