# 双轴通信协议

```text
AA AA X_DIR X_H X_L X_SUM Y_DIR Y_H Y_L Y_SUM FF FF
```

X_SUM=(X_DIR+X_H+X_L)&0xFF，Y_SUM同理。
步数为大端uint16，单位是脉冲；不是角度。方向0／1表示两个转向，具体正方向取决于电机安装。
方向2仅允许零步数控制包。全零步数停止两轴；仅某一轴零步数时，该轴停止旧动作，另一轴按新命令执行。

例：X方向1走50步，Y方向0走20步：

```text
AA AA 01 00 32 33 00 00 14 14 FF FF
```

运行中K230按键零步包：`AA AA 02 00 00 02 02 00 00 02 FF FF`。

MCU使用滑动窗口寻找完整帧，检查头尾、双校验和方向；失败不发布半帧。
ISR仅交接最新完整命令，主循环短临界区读取。不是可靠消息队列，也没有应用层ACK或独立通信看门狗。
手动模式忽略视觉动作；扫描模式收到有效视觉帧切入跟踪。跟踪丢失后没有自动回扫描逻辑。

运动换算：100毫度向下取整为1步，90度为1600步，30度为533步。视觉每帧上限50步。
手动／跟踪／扫描速度分别为30／10／60度每秒，实际频率受定时器范围限制。
