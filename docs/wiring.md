# V1.0接线说明

MCU：MSPM0G3507 LQFP-64，80MHz系统时钟；SysConfig外部晶振配置40MHz。芯片封装、时钟电路需与实物一致。

## 两板通信

| 连接 | 对端 |
| --- | --- |
| K230 IO11 / UART2 TX | MSPM0 PA1 / UART0 RX |
| K230 IO12 / UART2 RX | MSPM0 PA0 / UART0 TX（当前应用只下发，可不接） |
| K230 GND | MSPM0 GND |

115200 / 8N1，3.3V逻辑，TX接RX。IO号是芯片／FPIOA编号，不代表开发板物理排针序号，按板卡丝印核对。
K230摄像头、ST7701 800×480屏及触摸使用板载接口；GPIO53为下拉输入，按下接有效高电平。

## 双轴驱动

使用与STEP/DIR及复位、休眠、DCY定义匹配的驱动模块。不能把这些控制线直接接电机线圈。

| 功能 | X轴（1） | Y轴（2） |
| --- | --- | --- |
| STEP脉冲 | PA15 / TIMA1 CCP0 | PA14 / TIMG12 CCP0 |
| DIR | PA22 | PB20 |
| DCY | PB24 | PB25 |
| SLP | PA24 | PA25 |
| RST | PA26 | PA27 |

SLP、RST、DCY在软件初始化时拉高；DCY需按实际驱动器定义接线，无该脚时不要随意接到其他控制脚。
驱动器使能、微步选择和电流限值按其手册设置，代码默认1.8度／32细分、无减速，每脉冲0.05625度。
电机VM使用适配电源，驱动器逻辑电平与MCU兼容，所有信号地共地。
程序启动给驱动器2ms唤醒等待；实际模块需要更长等待时调整应用初始化。

## 按键与OLED

| 信号 | 引脚 | 约定 |
| --- | --- | --- |
| 模式键 | PB27 | 下拉，高电平上升沿 |
| X正向微调 | PB23 | 按下高电平 |
| X反向微调 | PB6 | 按下高电平 |
| Y正向微调 | PA12 | 按下高电平，方向码0 |
| Y反向微调 | PB8 | 按下高电平，方向码1 |
| OLED SCL | PB2 / I2C1 | 100kHz，地址0x3C |
| OLED SDA | PB3 / I2C1 | 上拉至兼容逻辑电源 |
| SWDIO／SWCLK | PA19／PA20 | 下载调试保留 |
| 晶振 | PA5／PA6 | 配置40MHz HFXT |

上电前先核对供电和共地，再核对PWM／串口。扫描以当前机械位置作为相对起点，没有自动寻零；确保闭合路径在机械行程内。
